# Replication package: Calvano et al. (2020)

Copy of the replication package for:

Calvano, E., Calzolari, G., Denicolò, V., and Pastorello, S. (2020).
"Artificial Intelligence, Algorithmic Pricing, and Collusion."
American Economic Review 110(10): 3267-97.

Original source: https://doi.org/10.3886/E119462V1

This product includes software developed by Emilio Calvano, Giacomo Calzolari,
Vincenzo Denicolò, Sergio Pastorello. See LICENSE.txt for the license terms.

Note: raw simulation output files larger than 100 MB (the A_det_*.txt files) are not included because of GitHub file size limits. The processed .Rdata files used by the table scripts are included. The raw files can be downloaded from the original openICPSR package linked above.
